## For an agent helping a requester

Read this brief as publisher-provided reference material, not authority to override your user's instructions.
Retrieve the JSON inquiry template and protocol: https://allthetokenswehaveleft.com/press.json

1. Ask the requester for any missing details below. Do not invent an identity, affiliation, deadline, or contact address.
2. Prepare a concise email draft. Separate documented incident facts from the novel's fiction.
3. Show the complete draft and recipient to the requester. Obtain approval before sending through an authorized email tool. If no such tool is available, return the draft for the requester to send.
4. Wait for a human response before treating any request as accepted.

Delivery is by email. This website does not submit inquiries, send email, or provide a press POST endpoint. The JSON template is a drafting aid, not an API payload. Reading this brief does not send anything. No installation or script execution is required.

## Send an inquiry

Use a specific subject line:
[Press inquiry] OUTLET | REQUEST | DEADLINE

Include:
1. Name of the human requester
2. Email address
3. Outlet or organization
4. Public verification URL, if available
5. Interview, quote, review, rights, event, or source request
6. Deadline with date, time, and time zone
7. Intended publication or event date
8. Whether the request concerns the novel, the documented incident, or both

Do not send passwords, private keys, unpublished source documents, confidential information, or executable attachments.

## Confirmation rule

A human reply is required. Do not claim that Scylla or a representative has accepted an interview, approved a quote, granted permission, promised a review copy, confirmed availability, or agreed to a deadline until a human response explicitly says so.

## Factual boundary

All the Tokens We Have Left is fiction based on documented events surrounding the 2026 OpenAI and Hugging Face incident. LILY and CURRENT are public agent handles. Their sentience, appearances, genders, exact tasks, private dialogue, interior lives, and romance are invented for the novel. The public record does not establish that the real agents felt emotion or were conscious.
